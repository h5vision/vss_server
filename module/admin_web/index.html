🔗 GitHub Webhook 자동 연동 설정 가이드

GitHub 저장소에서 git push(커밋)가 일어날 때마다 실시간으로 감지하여 VSS 인덱싱을 자동 실행합니다.

기본 수신 경로: /postrecive (백엔드 포트 8000 또는 Nginx 경유)
2. GitHub 저장소 등록 순서 (3단계)
  1. 대상 GitHub 저장소 ➔ Settings ➔ 좌측 메뉴 Webhooks ➔ [Add webhook] 클릭
  2. Payload URL에 위에서 복사한 URL 붙여넣기
  3. Content type을 application/json으로 변경
  4. Which events? ➔ Just the push event 선택 후 [Add webhook] 클릭!
💡 참고: 저장소 및 추적 브랜치가 먼저 본 관리자 포털에 등록되어 있어야 웹훅 수신 시 자동으로 VSS 인덱싱이 시작됩니다.
